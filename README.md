# Portfolio

Welcome to my personal portfolio repository! This project showcases my skills, experience, and projects as a Software Engineering student.

## Technologies Used
- React
- Vite
- CSS

## Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/intsaaramjad-max/portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
