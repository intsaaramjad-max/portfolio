# Intsaar Amjad - Personal Portfolio

This template provides a minimal setup for my personal portfolio, built to showcase my skills, projects, and experience as a Software Engineering student.

Currently, this project uses the following core technologies:

- [React](https://react.dev/) for component-based UI development
- [Vite](https://vitejs.dev/) for fast building and hot module replacement (HMR)
- Custom CSS for responsive and modern styling

## Getting Started

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/intsaaramjad-max/portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Expanding the Project

If you want to add new sections or modify the design, you can find the UI components inside the `src/components` directory. The project structure is kept simple to allow easy integration of new React components and CSS rules.
